****Personalized Early Sepsis Prediction Using Patient-Specific Physiological Baselines****

Abstract:
<br>
Sepsis is a life-threatening condition frequently encountered in intensive care units (ICUs), where delayed identification substantially increases mortality. Most prior work predicts sepsis directly from raw ICU vital-sign records at the population level. This study instead investigates whether patientspecific physiological baselines improve early sepsis prediction relative to conventional population-level features. Using the PhysioNet/Computing in Cardiology Challenge 2019 dataset, a perpatient baseline was established from the first 12 hours of records, deviations from that baseline were computed over hours 12–24, and sepsis onset between hours 24–48 was used as the prediction target. A total of 10,607 eligible patients were identified, with a 2.97% positive rate. Both a personalized (baseline-deviation) feature set and a conventional (raw population-level) feature set were evaluated using 12 machine learning models under class weighting and SMOTE, with cross-validated threshold tuning. The best conventional model (class-weighted RBF SVM) achieved PR-AUC 0.0775 and ROC-AUC 0.6337, while the best personalized model achieved PR-AUC 0.0768 and ROC-AUC 0.6014. Bootstrap testing found no statistically significant difference between the two representations. We conclude that patientspecific baseline personalization did not outperform conventional population-level features for this prediction task.
